Python Slot Machine

A simple slot machine game made with Python

Features

* Starts with a balance of 100
* Spin the slot machine
* Randomly generates slot symbols
* Gives different rewards depending on the result
* Updates the balance after each spin
* Includes a short delay between spins

How to Run

1. Make sure Python is installed
2. Clone this repository
3. Open the project folder in your terminal
4. Run


python slot_machine.py
